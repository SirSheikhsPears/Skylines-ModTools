# Mod Tools 3.8.1 [fix]

Mod debugging and reverse engineering tool for Cities: Skylines.

A maintenance fork of [BloodyPenguin's ModTools](https://github.com/bloodypenguin/Skylines-ModTools), updated for Cities: Skylines 1.21.2-f5.

## Changes

- ICities 1.21.0.0 compatibility.
- ScriptCompiler: assembly resolution fix.
- Restored F7 script compilation.

## Installation

Download `ModTools-3.8.1-INSTALL.zip` from [Releases](https://github.com/SirSheikhsPears/Skylines-ModTools/releases).

Extract its contents into:

`%LOCALAPPDATA%\Colossal Order\Cities_Skylines\Addons\Mods\`

Disable or unsubscribe from other versions of ModTools before use.
